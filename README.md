# Jarvis

Android AI personal assistant project for deep on-device control using Android APIs, Accessibility Service, Notification Listener, voice recognition, and text-to-speech.

## Phase 1
- Jetpack Compose control dashboard
- Voice command input
- Text-to-speech responses
- Accessibility Service for Back/Home/Recents/Notifications/Quick Settings, tap-by-text, scrolling, and typing
- Notification Listener for recent notifications
- System actions: flashlight, volume, battery status
- Launch installed apps by name
- GitHub Actions debug APK build

> This project is intended for personal/sideloaded use. Accessibility automation is powerful and should be enabled only when you trust the app.
