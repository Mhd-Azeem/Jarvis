# Jarvis Phase 1 Commands

- `open YouTube` — launches an installed app by name
- `flashlight on` / `flashlight off`
- `volume 40` — sets media volume percentage
- `battery` — speaks battery percentage
- `back`, `home`, `recents`
- `notifications`, `quick settings`
- `scroll down`, `scroll up`
- `tap Search` — clicks a visible UI element containing the requested text
- `type hello` — writes into the first visible editable field
- `read notifications` — speaks up to five recent notifications

Accessibility and Notification access must be enabled manually in Android Settings before the related commands can work.
